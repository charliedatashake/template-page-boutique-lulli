# Gabarit de page boutique, Lulli

Maquette de travail datashake. Elle présente le gabarit de page boutique à décliner sur les pages
`/toutes-nos-boutiques-mode/` de lulli-sur-la-toile.com, sur l'exemple de Lulli Marseille 1er.

Les blocs ont été injectés dans la page réelle avec les composants déjà présents sur le site
(cartes « nos bonnes adresses », widget FAQ des pages collection), donc dans la charte d'origine.
C'est une vraie page HTML : la navigation, les liens vers les pages du site et la FAQ fonctionnent.
Un bouton en bas à droite permet d'alterner entre la page nue et la page annotée.

Quatre blocs ajustés (intro, côté boutique, infos pratiques, balise de « nos créateurs »),
quatre blocs nouveaux (ce que vous trouvez en boutique, pour quelle occasion, nos autres adresses
à Marseille, FAQ). Les textes sont des exemples, la sélection par boutique reste à valider.

La police Antarctica du site n'étant pas chargeable en dehors de lulli-sur-la-toile.com,
elle est remplacée par Inter Tight, et les icônes du header par des équivalents dessinés.

Page non indexable (meta robots noindex).
